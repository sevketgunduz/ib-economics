# IB Economics

### → **[sevketgunduz.github.io/ib-economics](https://sevketgunduz.github.io/ib-economics/)**

Course materials for IB Diploma Programme Economics (SL and HL, first assessment 2022),
built on Hoang, Wray & Chakraborty, *Economics for the IB Diploma* (Hodder, 2020) and
aligned to the IB Economics guide.

- **[Course planner](https://sevketgunduz.github.io/ib-economics/course-planner.html)** is for teachers. It is a two-year plan
  covering all 36 chapters in 90-minute sessions. Each chapter has syllabus alignment, key
  terms, scenario-based explanations, diagram guidance, checklists and exam practice. The
  planner also includes 13 interactive diagram simulators and an SL/HL filter.
- **Student labs** are interactive lessons with graphs, simulations, a concept guide, a quiz
  and exam practice:
  - [Chapter 3: Demand](https://sevketgunduz.github.io/ib-economics/ch03-demand-lab.html)
  - [Chapter 4: Supply](https://sevketgunduz.github.io/ib-economics/ch04-supply-lab.html)
  - [Chapter 5: Competitive market equilibrium](https://sevketgunduz.github.io/ib-economics/ch05-equilibrium-lab.html)

The [site's front page](https://sevketgunduz.github.io/ib-economics/) shows the whole course
map, so the labs already written and those still to come are both visible.
